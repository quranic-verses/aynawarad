# اختبارات قرآنية

اختبارات يومية لحافظي القرآن الكريم، في ثلاثة أقسام، مع التدريب على الأجزاء المحفوظة:

- متشابهات القرآن الكريم: `index.html` (أين ورد؟)، `farq.html` (ميّز بينهما)
- تثبيت الحفظ: `akhir.html` (آخر الآية)، `qabl.html` (ما قبلها؟ ما بعدها؟)، `rattib.html` (رتّب الآيات)
- معلومات قرآنية: `lam.html` (لم تتكرر)، `makki.html` (مكية أم مدنية؟)، `fawatih.html` (فواتح السور)، `tartib.html` (ترتيب السور)، `asmaa.html` (أسماء السور)
- كل البيانات داخل ملف كل صفحة
- `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — التثبيت على الهاتف والعمل بدون إنترنت
- `privacy.html` — سياسة الخصوصية (عربي + English)، مطلوبة لمتجر Google Play
- `og-image.png` — صورة المعاينة عند مشاركة الرابط

الاختبار يتغير تلقائيًا كل يوم عند منتصف الليل بتوقيت القاهرة لكل اللاعبين. الاختبار رقم ١ هو يوم 2 أكتوبر 2026.
